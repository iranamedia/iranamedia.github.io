# رسانه ایرانا

تازه‌ترین رویدادهای ایران، شبانروزی سر هر ساعت کشور.

- اپ ایرانا: https://iranamedia.github.io
- کانال تلگرام: https://t.me/IranaMediaNews

هر بار که `bulletin/latest.json` به‌روز شود، GitHub متن خبرها را با صدای ElevenLabs می‌خواند، فایل صوتی را به کانال تلگرام می‌فرستد و اپ ایرانا را به‌روز می‌کند.

رازها (Settings → Secrets and variables → Actions): `ELEVENLABS_API_KEY`، `TELEGRAM_BOT_TOKEN`.
