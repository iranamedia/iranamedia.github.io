# عکس‌های شهریار ایران

عکس‌هایی از شاهزاده رضا پهلوی را که از حساب‌های رسمی ایشان برگزیده‌اید اینجا بارگذاری کنید (jpg یا png).
نام هر فایل را با تاریخ آغاز کنید، مانند `2026-11-07-frankfurt.jpg`.

تلویزیون ایرانا همه‌ی عکس‌های تازه‌ترین روز را (به ترتیب نام، تا ۶ عکس) یکی پس از دیگری پشت خبر شهریار ایران نشان می‌دهد،
با حرکت آرام دوربین و برچسب «عکس: حساب رسمی شهریار ایران». فایل‌هایی که نامشان با تاریخ آغاز نمی‌شود تنها هنگامی به کار می‌آیند
که هیچ عکس تاریخ‌داری نباشد. اگر عکسی نباشد، قاب تیتر ساده می‌آید.
