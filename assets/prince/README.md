# عکس‌های شهریار ایران

عکس‌هایی از شاهزاده رضا پهلوی را که از حساب‌های رسمی ایشان برگزیده‌اید اینجا بارگذاری کنید (jpg یا png).
نام هر فایل را با تاریخ آغاز کنید، مانند `2026-11-07-frankfurt.jpg`.

تلویزیون ایرانا تازه‌ترین عکس (به ترتیب نام) را پشت خبر شهریار ایران نشان می‌دهد،
با حرکت آرام دوربین و برچسب «عکس: حساب رسمی شهریار ایران». اگر عکسی نباشد، قاب تیتر ساده می‌آید.
